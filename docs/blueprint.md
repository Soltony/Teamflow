# **App Name**: TeamFlow

## Core Features:

- Project Registration: Project Registration: Input project details including timeline, detailed tasks, and weight percentages.
- Team Assignment: Team Assignment: Assign tasks to specific teams and designate a team leader for each task.
- Activity Management: Activity Management: Track and manage team activity online.
- Gantt Chart: Gantt Chart Visualization: Automatically generate and display Gantt charts for each project based on entered timelines and tasks.
- Task Suggestion: Task Suggestion: Use an AI tool to provide suggestions for task descriptions, improving clarity and completeness.

## Style Guidelines:

- Primary color: Teal blue (#4db6ac) to give the application a professional and friendly appearance.
- Background color: Light gray (#f0f4c4) for a clean, neutral backdrop that keeps the focus on the content.
- Accent color: Soft yellow (#ffb74d) to highlight important actions.
- Body and headline font: 'Inter' sans-serif for a clean, readable design.
- Use flat, line-based icons to represent different project activities and statuses.
- A clear, tabular layout will show the progress and important dates of each task.
- Use smooth transitions to visualize and reflect task completion.
